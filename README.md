# Adoptuj Chřipku

Satirická landing page pro fiktivní službu „Adoptuj Chřipku“. Web obsahuje veselý hero blok, animované kapénky, objednávkový formulář a jazykové varianty včetně japonštiny, klingonštiny, Jawi malajštiny a režimu „Já jsem Groot“.
